# AI 기능 개발 워크플로우

AI 관련 기능(시스템 프롬프트, 챗봇, 에이전트 등) 개발 시 따르는 워크플로우입니다.

## 개요

AI 기능 개발은 다음 핵심 영역을 포함합니다:
- 시스템 프롬프트 관리
- 대화 컨텍스트 처리
- 모델 통합
- 응답 스트리밍

## 개발 단계

### 1. 요구사항 분석
- AI 기능의 목적 명확화
- 사용자 시나리오 정의
- 입출력 형식 결정

### 2. 아키텍처 설계
- 프롬프트 구조 설계
- 컨텍스트 관리 방식 결정
- 에러 처리 전략 수립

### 3. TDD 기반 구현
```typescript
// 테스트 먼저 작성
describe('AI Feature', () => {
  it('should handle user query correctly', async () => {
    // 테스트 로직
  });
});
```

### 4. 프롬프트 시스템 통합
- `careti-src/core/prompts/` 활용
- JSON 기반 프롬프트 템플릿
- 다국어 지원 고려

### 5. 검증 및 테스트
- 다양한 입력에 대한 응답 확인
- 에러 케이스 처리 확인
- 성능 테스트

## 주요 파일 참조

| 파일 | 용도 |
|-----|------|
| `src/core/prompts/` | 프롬프트 시스템 |
| `careti-src/core/prompts/` | Caret 전용 프롬프트 |
| `.agents/context/system-prompt.md` | 시스템 프롬프트 가이드 |
