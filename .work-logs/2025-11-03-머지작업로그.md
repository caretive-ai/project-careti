## 🚀 Cline v3.34.0 주요 기능 추가

### 1. CLI & Subagent 시스템 (핵심 신규 기능)

**개요**:
- Cline을 CLI 환경에서 독립 실행 가능하도록 확장
- Subagent 패턴 지원으로 멀티 에이전트 오케스트레이션 가능
- JetBrains IDE와 설정 공유 (`~/.cline/data/` 디렉토리)

**관련 파일**:
```
src/integrations/cli-subagents/
  └── subagent_command.ts
src/utils/cli-detector.ts
src/standalone/
  ├── cline-core.ts
  └── hostbridge-client.ts
src/core/prompts/system-prompt/components/cli_subagents.ts
```

**주요 특징**:
- ✅ 독립 실행 모드 (`cline-cli` 명령어)
- ✅ 서브에이전트 명령 감지 및 실행
- ✅ 설정 파일 공유 (VS Code ↔ CLI ↔ JetBrains)
- ✅ 마크다운 스트리밍 UX
- ✅ 체크포인트 복원 기능
- 🚧 OpenAI Compatible 지원 (PR 머지됨, npm 릴리즈 대기)

**사용 사례**:
1. **모바일 앱 백엔드**: 서버에서 cline-cli 실행, 모바일 앱이 API 호출
2. **오케스트레이터 패턴**: Cline이 다른 Cline 에이전트를 호출
3. **멀티 모델 전략**: 탐색용 경량 모델 + 아키텍처용 강력한 모델
4. **커스텀 UI**: CLI 위에 독자적인 GUI 구축

**참고 문서**: `.caretrules/cline-cli-subagent-research.md`
