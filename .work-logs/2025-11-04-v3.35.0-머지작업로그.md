## 문제 발생 시 대응

### Compilation 실패
1. `./scripts/3way-diff.sh [문제파일]` 실행
2. 에러 메시지 분석
3. CARET MODIFICATION 주석 확인
4. 타입 불일치 해결
5. 재컴파일

### Test 실패
1. 테스트 로그 확인
2. 해당 기능 수동 테스트
3. Caret 기능인지 Cline 기능인지 확인
4. 필요 시 테스트 업데이트
5. 재실행

### Runtime 에러
1. Logger 출력 확인
2. 해당 코드 3-way diff 확인
3. Caret 변경 누락 확인
4. Cline 변경 오적용 확인
5. 수정 후 재테스트

### 충돌 해결 실패 (최후)
1. 해당 Stage 롤백
2. 더 상세한 분석 수행
3. 대안 전략 수립
4. 필요 시 사용자 확인 요청
5. 재시도
