# CodeCenter 변경 기록

## [1.0.0]

- **Caret 기반 기업용 에디션**: Caret v0.1.3을 기반으로 한 기업용 AI 코딩 어시스턴트
- **전문 개발 환경 최적화**: 엔터프라이즈 개발을 위한 전문적인 AI 코딩 어시스턴트로 설계
- **Slexn 브랜딩**: Slexn 회사의 CodeCenter 제품으로 브랜딩
- **기업용 기능 강화**:
  - 보안 강화된 코드 생성
  - 기업 정책 준수 가이드라인
  - 팀 협업 기능 향상
  - 엔터프라이즈 지원 체계

## 베이스 버전 정보

CodeCenter는 다음 버전들을 기반으로 합니다:
- **Caret v0.1.3**: 한국어/일본어/중문 지원, 페르소나 시스템
- **Cline v3.26.6**: 최신 AI 모델 지원, Plan/Act 모드
