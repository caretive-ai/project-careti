# 머징 작업 후 i18n 시스템 관리 워크플로우

**Cline 원본과 머징 작업 후 i18n 시스템을 체계적으로 관리하기 위한 완전한 가이드**

## 📋 개요

Cline 원본 저장소와의 머징 작업 후에는 i18n 시스템에 다음과 같은 문제들이 발생할 수 있습니다:
- 새로 추가된 컴포넌트의 하드코딩된 텍스트
- 기존 i18n 키의 사용 중단으로 인한 미사용 키 발생
- 일부 언어에서의 번역 누락
- 코드에서 사용하지만 JSON에 정의되지 않은 키

이 워크플로우는 이러한 문제들을 체계적으로 해결하기 위한 3단계 프로세스를 제공합니다.

## 🛠️ 도구 개요

### 1. 파일 기반 분석 도구
```bash
# 하드코딩된 텍스트가 있는 파일 식별
node caret-scripts/tools/report-i18n-missing-file.js
```
**용도**: 새로 추가되거나 수정된 파일에서 i18n 작업이 필요한 부분 식별

### 2. 키 기반 종합 분석 도구
```bash
# i18n 키 사용 현황 종합 분석
node caret-scripts/tools/report-i18n-unused-key.js
```
**용도**: 누락 번역, 정의되지 않은 키, 미사용 키를 한 번에 분석

## 🔄 머징 후 i18n 관리 워크플로우

### Phase 1: 현황 파악 (머징 직후)

#### 1.1 새로운 하드코딩 텍스트 식별
```bash
# 1. 하드코딩된 파일 분석
node caret-scripts/tools/report-i18n-missing-file.js

# 2. 결과 확인
# - 새로 추가된 파일들에 i18n 적용 필요 여부 파악
# - 기존 파일의 새로운 하드코딩 텍스트 확인
```

#### 1.2 전체 i18n 시스템 현황 분석
```bash
# 종합 분석 실행
node caret-scripts/tools/report-i18n-unused-key.js

# 생성되는 보고서 확인
cat caret-scripts/i18n-unused-keys-report.md
```

### Phase 2: 우선순위 기반 문제 해결

#### 2.1 [ ] 누락 번역 분석 및 해결
**우선순위**: 🔥 최우선 (사용자 경험 직결)

**작업 절차**:
1. **고우선순위 번역 추가**:
   ```bash
   # 보고서에서 🔥 표시된 키들 확인
   # 실제 사용중인 키들의 누락 번역 우선 처리
   ```

2. **번역 작업**:
   ```bash
   # 각 언어별 JSON 파일에 번역 추가
   # ko/common.json, en/common.json, ja/common.json, zh/common.json
   ```

3. **검증**:
   ```bash
   # 번역 추가 후 재분석
   node caret-scripts/tools/report-i18n-unused-key.js
   ```

#### 2.2 [ ] 정의되지 않은 키 탐지 및 해결
**우선순위**: 🔥 최우선 (기능 오류 방지)

**작업 절차**:
1. **키 누락 확인**:
   ```bash
   # 보고서의 "정의되지 않은 키" 섹션 확인
   # 🔥 표시된 키들(여러 컴포넌트에서 사용) 우선 처리
   ```

2. **키 정의 추가**:
   ```bash
   # 적절한 namespace JSON 파일에 키 추가
   # 예: account.* 키들은 common.json의 account 섹션에 추가
   ```

3. **번역 완성**:
   ```bash
   # 새로 추가한 키들에 대해 모든 언어 번역 추가
   # ko, en, ja, zh 모든 locale 파일 업데이트
   ```

#### 2.3 [ ] 미사용 키 탐지 및 정리
**우선순위**: ⚪ 낮음 (시스템 최적화)

**작업 절차**:
1. **미사용 키 검토**:
   ```bash
   # 보고서의 "미사용 키" 섹션 검토
   # 향후 사용 예정인지, 완전히 불필요한지 판단
   ```

2. **안전한 제거**:
   ```bash
   # 확실히 불필요한 키들만 제거
   # 모든 locale 파일에서 동시에 제거
   ```

3. **최종 검증**:
   ```bash
   # 빌드 테스트
   npm run compile
   npm run test:webview
   ```

