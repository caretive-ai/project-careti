# Multilingual i18n System

Caret의 **다국어 지원 시스템**은 한국어, 영어, 일본어, 중국어 4개 언어를 완전 지원하는 포괄적인 국제화 시스템입니다.

## 📋 **기능 개요**

### **지원 언어**
- 🇰🇷 **한국어 (ko)**: 완전 번역 및 현지화 (조사 자동 처리 포함)
- 🇺🇸 **영어 (en)**: 기본 언어 및 fallback
- 🇯🇵 **일본어 (ja)**: 완전 번역 및 현지화
- 🇨🇳 **중국어 (zh)**: 완전 번역 및 현지화

### **네임스페이스 구조**
각 언어마다 **7개 네임스페이스**로 체계적 관리:

| 네임스페이스 | 용도 | 예시 |
|-------------|------|------|
| **common** | 공통 UI 요소 | 버튼, 메뉴, 일반 메시지 |
| **welcome** | 환영 페이지 | 온보딩, 시작 가이드 |
| **persona** | AI 페르소나 | 캐릭터 설명, 특성 |
| **settings** | 설정 페이지 | 옵션, 구성 항목 |
| **validate-api-conf** | API 검증 | 오류 메시지, 검증 안내 |
| **announcement** | 공지사항 | 업데이트, 알림 |
| **models** | AI 모델 설명 | 모델 특성, 사용법 |

**총 30개 JSON 파일** (7 네임스페이스 × 4 언어 + 일본어/중국어 rules.json 추가)

## 🏗️ **시스템 아키텍처**

### **파일 구조**
```
webview-ui/src/caret/
├── locale/                        # 다국어 JSON 파일
│   ├── en/ (7개)                  # 영어 (기본)
│   ├── ko/ (7개)                  # 한국어
│   ├── ja/ (8개)                  # 일본어 (+rules.json)
│   └── zh/ (8개)                  # 중국어 (+rules.json)
├── utils/
│   ├── i18n.ts                    # 메인 i18n 유틸리티
│   ├── i18n-performance.ts        # 성능 모니터링 & 캐싱
│   └── lazy-i18n.ts              # 지연 로딩 시스템
├── hooks/
│   └── useCaretI18n.ts           # React i18n Hook
├── context/
│   └── CaretI18nContext.tsx      # i18n Context Provider  
└── components/
    ├── CaretUILanguageSetting.tsx        # 언어 설정 UI
    └── CaretGeneralSettingsSection.tsx   # 설정 페이지 통합
```

### **핵심 API**
```typescript
// 번역 함수
export const t = (
    key: string, 
    namespace: string = "common",
    options?: Record<string, string | number>,
    language?: SupportedLanguage
): string

// React Hook 사용법
const { t, currentLanguage, changeLanguage } = useCaretI18n()

// 사용 예시
t("settings.telemetry.label", "settings")           // → "Allow anonymous error reporting"
t("welcome.title", "welcome")                       // → "Welcome to Caret"
changeLanguage("ko")                                // 언어 변경
```

### **한국어 조사 처리**
```typescript
// 한국어 자동 조사 처리 예시
t("message.save", "common", { name: "파일" })    // → "파일을 저장합니다"
t("message.save", "common", { name: "이미지" })   // → "이미지를 저장합니다"
```

### **공통 UI 요소 (common 네임스페이스)**

### **설정 페이지 (settings 네임스페이스)**
| 키 | 한국어 (ko) | 영어 (en) | 일본어 (ja) | 중국어 (zh) |
|----|------------|----------|------------|------------|  
| `settings.uiLanguage.label` | UI 언어 | UI Language | UI言語 | UI语言 |
| `telemetry.label` | 익명 오류 및 사용 보고 허용 | Allow anonymous error reporting | 匿名エラーレポートを許可 | 允许匿名错误报告 |

## 🎯 **사용법**

### **기본 사용법**

```typescript
import { useCaretI18n } from '@/caret/hooks/useCaretI18n'

function MyComponent() {
    const { t, currentLanguage, changeLanguage } = useCaretI18n()

    return (
        <div>
            <h1>{t("welcome.title", "welcome")}</h1>
            <p>{t("common.button.save")}</p>
            <button onClick={() => changeLanguage('ko')}>
                한국어로 변경
            </button>
        </div>
    )
}
```

### **한국어 조사 자동 처리**

```typescript
// 한국어에서 자동으로 조사가 처리됩니다

// "파일을 저장합니다" (받침 있음)

t("message.save", "common", { name: "이미지" })  
// "이미지를 저장합니다" (받침 없음)
```
