### 🎭 **Caret vs Cline 이해 (기본 필수)**

**⚠️ 모든 AI가 반드시 알아야 할 핵심 개념**:

**Caret = Cline + 주요 개선사항들**
- **Plan/Act Mode**: Cline 기본 기능 (실행 전 계획 vs 바로 실행)  
- **Chatbot/Agent Mode**: Caret 추가 기능 (대화형 vs 자동실행)
- **시스템 프롬프트**: Cline 707줄 하드코딩 → Caret JSON 모듈 시스템 (53-69% 토큰 절약)
- **페르소나 시스템**: 4개 AI 캐릭터 (오사랑, 마도베, 사이안, 탄도)
- **규칙 우선순위**: .clinerules > .cursorrules > .windsurfrules (중복 방지)
- **다국어 처리**: 한국어/영어/일본어/중국어 + i18n 프레임워크
- **로깅 시스템**: 프론트엔드/백엔드 통합 로깅 + 디버그 모드
- **UI/UX 개선**: 접근성, 성능 최적화, 사용자 친화적 인터페이스
- **둘은 독립적**: Caret이 Cline 위에 얹어진 별개 레이어

## ⚡ **효율적인 독해 전략**

### 🎯 **단계별 접근**

1. **작업 성격 파악** (30초): 키워드 추출 → 카테고리 분류
2. **필수 문서 선택** (1분): 매핑 테이블 기반 문서 선택
3. **선택적 독해** (5-10분): 필요한 섹션만 집중 독해
4. **실행 전 체크** (1분): .caretrules 체크리스트 재확인

### 📚 **독해 우선순위**

1. **High Priority**: 직접 관련된 핵심 문서 (1-2개)
2. **Medium Priority**: 간접 관련 문서 (필요시만)
3. **Low Priority**: 참고용 문서 (링크만 확인)

### 🔍 **스마트 독해 방법**

- **목차 우선 스캔**: 관련 섹션만 식별
- **키워드 검색**: 구체적인 내용 빠르게 찾기
- **예제 코드 우선**: 실제 구현 패턴 확인
- **체크리스트 활용**: 놓치기 쉬운 필수 사항 점검

## 📝 **다음 세션 가이드 작성 원칙**

### 🎯 **목적**
AI 세션 전환 시 새로운 AI가 전체 맥락을 즉시 이해하고 작업을 이어갈 수 있도록 함

### 📋 **필수 포함 요소**

1. **작업 컨텍스트 (상위→하위)**
   ```
   - 상위 작업: [링크] (예: 006-upstream-merge-conflict-resolution-plan.md)
   - 현재 작업: [구체적 설명과 진행 상황]
   - 다음 작업: [명확한 목표와 우선순위]
   ```

2. **🚨 MANDATORY: 필수 읽기 문서 목록**
   ```markdown
   필수 읽기:
   - @next-session-guide.md (현재 작업 상황)
   - @ai-work-index.mdx (AI Work Index Guide)
   - @{task-plan}.md (작업 계획서)  
   - @{related-guide}.mdx (작업 성격별 가이드)
   
   현재 상황: [구체적 진행 상황]
   다음 우선순위: [명확한 첫 번째 할 일]
   ```

3. **참조 문서 체계**
   ```
   작업 성격별 필수 문서:
   - .caretrules (프로젝트 규칙)
   - [작업 문서] (예: 006-5-webview-separation-strategy.md)
   - [관련 가이드] (예: upstream-merging.mdx)
   
   선택 읽기:
   - [보조 문서들]
   ```

3. **현재 상태 스냅샷**
   ```
   - 브랜치: [현재 브랜치명]
   - 변경 파일: [주요 변경사항]
   - 컴파일 상태: [에러 수/성공 여부]
   - 테스트 상태: [통과/실패]
   ```

4. **핵심 결정사항**
   ```
   - [이미 결정된 중요 사항]
   - [주의해야 할 제약사항]
   - [유지해야 할 원칙]
   ```

5. **구체적 다음 단계**
   ```
   1. [첫 번째 작업] - 명령어 포함
   2. [두 번째 작업] - 검증 방법 포함
   3. [세 번째 작업] - 예상 결과 포함
   ```

### ❌ **피해야 할 실수**

- 지엽적 세부사항만 나열 (전체 그림 누락)
- 참조 문서 링크 없이 작업 설명만
- "이전 대화 참조" 같은 모호한 표현
- 실행 명령어 없는 추상적 설명
