# 시스템 프롬프트 관리 규칙

이 문서는 일관성과 유지보수성을 보장하기 위해 Caret의 시스템 프롬프트를 관리하고 편집하는 규칙을 설명합니다.

## 핵심 원칙

시스템 프롬프트는 JSON 설정 파일과 그에 해당하는 사람이 읽을 수 있는 한국어 마크다운 문서의 조합을 통해 관리됩니다. 이를 통해 AI와 개발자 모두 AI의 행동에 대해 명확하고 동기화된 이해를 갖게 됩니다.

## 편집 워크플로우

AI의 핵심 행동을 수정할 때, 다음 파일들은 반드시 **쌍으로 함께 편집되어야 합니다**:

1.  **JSON 설정 (`/caret-src/core/prompts/sections/`)**:
    -   이것이 시스템이 직접 로드하는 정보의 원천(source of truth)입니다.
    -   예시: `AGENT_BEHAVIOR_DIRECTIVES.json`

2.  **한국어 마크다운 문서 (`/caret-docs/system-prompts-ko/`)**:
    -   이 문서는 JSON 파일의 내용과 구조를 직접적으로, 사람이 읽을 수 있게 번역한 것이어야 합니다.
    -   예시: `agent-behavior-directives.md`

## 동기화 규칙

**프롬프트 관련 JSON 파일에 대한 모든 변경은 반드시 그에 상응하는 한국어 마크다운 파일의 변경을 동반해야 하며, 그 반대도 마찬가지입니다.**

이 규칙은 문서가 항상 현재 시스템의 행동을 반영하도록 보장하여, 혼란을 방지하고 모든 개발자를 위한 명확한 참조 소스를 유지합니다.
