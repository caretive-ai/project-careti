# Account & Organization System

Caret의 **계정 및 조직 관리 시스템**은 Auth0 기반의 보안 강화된 인증과 팀 단위 계정 관리를 제공하는 완전히 독립적인 기능입니다.

## 📋 **기능 개요**

### **Caret만의 고유 기능**

- **Auth0 기반 계정 시스템**: 보안 강화된 로그인 및 인증
- **Organization 관리**: 팀/조직 단위 계정 관리
- **요금제 시스템**: 사용량 기반 과금 및 제한 관리
- **사용량 대시보드**: 실시간 API 사용량 모니터링
- **팀 협업**: 조직 내 멤버 관리 및 권한 설정

### **차별화 포인트**

- **Cline과 완전 분리**: 독립적인 API 시스템으로 충돌 없음
- **엔터프라이즈 지원**: 대규모 팀 및 조직 지원
- **투명한 과금**: 명확한 사용량 추적 및 요금 체계

```typescript
// 1. 로그인 프로세스

```

## 🔐 **인증 시스템**

### **Auth0 통합**

- **JWT 토큰 기반**: 보안 강화된 인증 방식
- **커스텀 토큰**: Caret 전용 API 키 별도 관리
- **사용자 정보 추출**: 이름, 이메일, 프로필 이미지

### **API 키 관리**

```typescript
// caretApiKey vs apiKey 분리 관리
const apiConfiguration = {
	apiProvider: "gemini", // 사용자가 선택한 AI 모델
	caretApiKey: "caret_xxx", // Caret 계정 API 키 (별도)
	// ... 기타 AI 모델 설정들
}

// Caret API 호출 시
const response = await fetch(API_ENDPOINT, {
	headers: {
		Authorization: `Bearer ${caretApiKey}`,
		"Content-Type": "application/json",
	},
})
```
