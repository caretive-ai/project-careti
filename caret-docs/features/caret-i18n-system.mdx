## 🌍 **개요**

Caret의 i18n(국제화) 시스템은 **4개 언어**(한국어, 영어, 일본어, 중국어)를 지원하며, **동적 브랜드명 변경** 및 **하이브리드 래핑 전략**을 통해 Cline 원본 코드 수정을 최소화하면서 전체 UI의 다국어화를 달성합니다.

### **핵심 차별화 요소**

1. **🔄 Self-Reference i18n 키**: `{{brand.appName}}` 템플릿으로 Caret ↔ CodeCenter 동적 변경
2. **🎯 하이브리드 래핑**: Cline 원본 컴포넌트를 래퍼로 감싸 i18n 적용
3. **🚀 성능 최적화**: 언어별 lazy loading과 캐싱 시스템
4. **🛡️ 완벽한 fallback**: 번역 누락 시 영어 → 한국어 → 키 이름 순서로 fallback

## 🚀 **핵심 기능**

### **1. Self-Reference 템플릿 시스템**

동적 브랜드명 변경을 위한 혁신적인 템플릿 엔진:

```json
// common.json
{
  "brand": {
    "appName": "Caret",
    "appNameUpper": "CARET",
    "appNameLower": "caret",
    "appNameKorean": "캐럿"
  },
  "welcome": {
    "title": "Welcome to {{brand.appName}}! 🎉",
    "description": "{{brand.appName}} is your AI-powered coding assistant"
  }
}

// ko/common.json (한글 조사 지원)
{
  "brand": {
    "appName": "캐럿",
    "appNameUpper": "캐럿",
    "appNameLower": "캐럿"
  },
  "welcome": {
    "title": "{{brand.appName|을}} 사용해보세요! 🎉",
    "description": "{{brand.appName|은}} 당신의 AI 코딩 어시스턴트입니다",
    "startWith": "{{brand.appName|로}} 개발을 시작하세요"
  }
}
```

**한글 조사 처리 템플릿 엔진**:

```typescript
// 한글 조사 규칙 매핑
const koreanJosaRules = {
	을: (word: string) => (hasLastConsonant(word) ? "을" : "를"),
	은: (word: string) => (hasLastConsonant(word) ? "은" : "는"),
	이: (word: string) => (hasLastConsonant(word) ? "이" : "가"),
	로: (word: string) => (hasLastConsonant(word) ? "으로" : "로"),
	와: (word: string) => (hasLastConsonant(word) ? "과" : "와"),
}

const replaceTemplateVariables = (text: string, translations: any, language: string): string => {
	return text.replace(/\{\{([^}]+)\}\}/g, (match, expression) => {
		// 한글 조사 처리 (예: brand.appName|을)
		if (language === "ko" && expression.includes("|")) {
			const [keyPath, josa] = expression.split("|")
			const value = getNestedValue(translations, keyPath)
			if (value && koreanJosaRules[josa]) {
				return value + koreanJosaRules[josa](value)
			}
		}

		// 기본 브랜드 처리
		if (expression.startsWith("brand.")) {
			const brandKey = expression.substring(6)
			return translations.brand?.[brandKey] || match
		}

		return match
	})
}

// 결과 예시:
// "캐럿을 사용해보세요! 🎉" (캐럿 + 을)
// "코드센터를 사용해보세요! 🎉" (코드센터 + 를)
```

**받침 검사 헬퍼 함수**:

```typescript
const hasLastConsonant = (word: string): boolean => {
	if (!word || word.length === 0) return false

	const lastChar = word[word.length - 1]
	const lastCharCode = lastChar.charCodeAt(0)

	// 한글 유니코드 범위 확인 (가-힣: 44032-55203)
	if (lastCharCode >= 44032 && lastCharCode <= 55203) {
		// 종성 확인: (유니코드 - 44032) % 28
		return (lastCharCode - 44032) % 28 !== 0
	}

	// 영어/숫자인 경우 발음에 따른 처리
	const consonantEnding = /[bcdfgjklmnpqrstvwxz]$/i.test(lastChar)
	return consonantEnding
}
```

### **3. 완벽한 Fallback 시스템**

```typescript
export const t = (key: string, namespace: string = "common"): string => {
	const currentLang = getCurrentLanguage()

	// 1차: 현재 언어에서 찾기
	let value = getNestedValue(translations[currentLang]?.[namespace], key)
	if (value) return replaceTemplateVariables(value, translations[currentLang])

	// 2차: 영어에서 찾기
	value = getNestedValue(translations.en[namespace], key)
	if (value) return replaceTemplateVariables(value, translations.en)

	// 3차: 한국어에서 찾기
	value = getNestedValue(translations.ko[namespace], key)
	if (value) return replaceTemplateVariables(value, translations.ko)

	// 최후: 키 이름 그대로 반환
	return key
}
```

```typescript
const loadLanguagePack = async (lang: SupportedLanguage) => {
	const translations = await import(`../locale/${lang}/index.ts`)
	return translations.default
}

// 사용자가 언어 변경 시에만 해당 언어팩 로딩
const changeLanguage = async (newLang: SupportedLanguage) => {
	if (!loadedLanguages.has(newLang)) {
		const langPack = await loadLanguagePack(newLang)
		translations[newLang] = langPack
		loadedLanguages.add(newLang)
	}
	setCurrentLanguage(newLang)
}
```

### **2. 메모이제이션 및 캐싱**

```typescript
const translationCache = new Map<string, string>()

export const t = useMemo(() => {
	return (key: string, namespace: string = "common"): string => {
		const cacheKey = `${getCurrentLanguage()}_${namespace}_${key}`

		if (translationCache.has(cacheKey)) {
			return translationCache.get(cacheKey)!
		}

		const result = performTranslation(key, namespace)
		translationCache.set(cacheKey, result)
		return result
	}
}, [getCurrentLanguage()])
```

## 🌍 **다국어 콘텐츠 품질**

### **번역 가이드라인**

1. **일관성**: 동일한 개념은 동일한 번역 사용
2. **간결성**: UI 공간 제약을 고려한 간결한 번역
3. **자연스러움**: 각 언어의 자연스러운 표현 방식 사용
4. **기술 용어**: 프로그래밍 용어는 영어 원문 병기

### **품질 보증 프로세스**

```typescript
// 번역 품질 검증 도구
const translationValidator = {
	// 누락된 번역 키 검사
	checkMissingKeys: (baseLang: string, targetLang: string) => {
		const baseKeys = extractAllKeys(translations[baseLang])
		const targetKeys = extractAllKeys(translations[targetLang])
		return baseKeys.filter((key) => !targetKeys.includes(key))
	},

	// 번역 텍스트 길이 검사 (UI 깨짐 방지)
	checkTextLength: (key: string) => {
		const lengths = Object.entries(translations).map(([lang, trans]) => ({
			lang,
			length: getNestedValue(trans, key)?.length || 0,
		}))

		const maxLength = Math.max(...lengths.map((l) => l.length))
		const minLength = Math.min(...lengths.map((l) => l.length))

		if (maxLength / minLength > 2) {
			console.warn(`Text length variation too high for key: ${key}`)
		}
	},
}
```
