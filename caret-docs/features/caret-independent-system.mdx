# Caret 독립 시스템 (Chatbot/Agent 모드) 이해 가이드

Caret의 **Chatbot/Agent 시스템**은 Cline의 Plan/Act 모드를 완전히 새로운 방식으로 재해석한 독립적 AI 상호작용 시스템입니다.

## 🤔 **Plan/Act vs Chatbot/Agent - 핵심 차이점**

### **1. 사용자 경험 차이**

| 구분            | Cline Plan/Act               | Caret Chatbot/Agent              |
| --------------- | ---------------------------- | -------------------------------- |
| **경험 방식**   | 분절된 경험 (계획→승인→실행) | 단일 연속 경험 (자연스러운 대화) |
| **AI 역할**     | 도구 사용 중심               | 대화와 협업 중심                 |
| **사용자 관점** | 기술적 용어 (Plan/Act)       | 직관적 용어 (Chatbot/Agent)      |

### **2. AI 행동 패턴 차이**

#### **🤖 Chatbot Mode (상담사 역할)**

- **AI 태도**: "이 방법은 어떠신가요?", "더 궁금한 점이 있으신가요?"
- **주도권**: 개발자가 주도, AI는 조언과 분석만 제공
- **안전성**: 위험한 작업(파일 수정, 명령 실행) 차단
- **용도**: 코드 리뷰, 기술 상담, 아키텍처 조언

#### **⚡ Agent Mode (협력 파트너 역할)**

- **AI 태도**: "이 작업을 진행하겠습니다", "다음 단계로 넘어갑니다"
- **주도권**: AI가 주도, 모든 개발 작업 직접 수행
- **자유도**: 모든 도구 사용 + 자유로운 대화 가능
- **용도**: 기능 구현, 버그 수정, 자동화 작업

### **3. 시스템 프롬프트 차이**

#### **기존 Plan/Act (Cline)**

```
PLAN MODE: "계획을 세우고 승인을 받으세요"
ACT MODE: "도구를 사용하여 작업을 수행하세요"
```

#### **새로운 Chatbot/Agent (Caret)**

```
CHATBOT MODE: "Expert consultation and guidance mode -
               분석과 조언에 집중하되 변경은 하지 마세요"

AGENT MODE: "Collaborative development mode -
            분석과 실행을 결합하여 협력적으로 개발하세요"
```

## 🏗️ **기술 아키텍처: 어댑터 패턴**

### **핵심 설계 원칙**

1. **해석적 독립성**: Cline 인프라를 재사용하되 다르게 해석

    ```typescript
    // 같은 mode: "act"이지만...
    Cline → "ACT MODE" (도구 실행 모드)
    Caret → "AGENT MODE - 협력적 개발 파트너" (완전히 다른 의미)
    ```

2. **인프라 공유**: Cline의 `tools`, `apiConfiguration`, `TaskServiceClient` 재사용
3. **의미론적 분리**: 사용자는 "Agent/Chatbot"만 보고 "Plan/Act"는 숨김

#### **🔄 어댑터 패턴 최종 완성**

- **ModeSystemRegistry**: 백엔드 분기 로직 중앙 집중화 (33/33 TDD 테스트 통과)
- **CaretModeAdapter**: 상수 기반 안전한 모드 해석 변환

    ```typescript
    // 타입 안전한 상수 활용
    CaretModeAdapter.adaptSystemPrompt(CLINE_MODES.ACT, MODE_SYSTEMS.CARET)
    → SYSTEM_PROMPTS.CARET.AGENT // "AGENT MODE"

    CaretModeAdapter.toBackendMode(CARET_MODES.CHATBOT)
    → CLINE_MODES.PLAN // "plan"
    ```

- **하드코딩 제거**: 모든 "caret", "agent", "chatbot" 문자열이 상수로 대체
- **자동 도구 상속**: 새로운 Cline 도구 → Caret 정책 필터링 → 사용자 제공

#### **🔧 신기술 호환성 보장 (2025-08-28 업데이트)**

- **Handler 아키텍처 적용**: 최신 Cline의 `PlanModeRespondHandler` 기반으로 전환 예정
- **Forward Compatibility**: 새로운 Handler 패턴으로 Cline 신기술 자동 반영
- **Zero Maintenance**: Handler 상속으로 수동 업데이트 최소화
- **Caret 정체성 유지**: 기술은 공유하되 사용자 경험은 독립적

#### **🎯 다음 단계: Handler 전환 계획**

1. **AgentModeRespondHandler** ← `PlanModeRespondHandler` 상속
2. **ChatbotModeRespondHandler** ← `PlanModeRespondHandler` 상속
3. **버튼 제거 지원**: 자연스러운 대화 흐름 구현
4. **스트리밍 지원**: 실시간 응답 표시

### **사용자 인터페이스 (2025-08-25 최종 완성)**

- **직관적 용어**: "Plan/Act" 대신 "Chatbot/Agent" 사용
- **실시간 전환**: 설정 변경 시 UI와 백엔드 동기화
- **자연스러운 대화 흐름**: ✅ **Agent 모드에서 AI 응답 후 즉시 대화 가능** (Phase 12 완성)
- **Cline Act 완벽 호환**: Cancel 버튼 제거로 원활한 대화 환경 구현
- **하위 호환성**: 기존 Cline 사용자 워크플로우 보존

## 📋 **구체적 기능 차이**

### **🤖 Chatbot Mode - 안전한 AI 상담사**

#### **허용되는 기능**

- ✅ **파일 읽기**: 코드 분석, 문서 검토 (`read_file`, `search_files`)
- ✅ **자유 대화**: 질문-답변, 기술 상담, 설명 요청
- ✅ **웹 검색**: 자료 조사, 문서 참조 (`browser_action`)

#### **차단되는 기능**

- ❌ **파일 수정**: `write_to_file`, `replace_in_file` 완전 차단
- ❌ **명령 실행**: `execute_command` 차단으로 터미널 명령 불가
- ❌ **위험 작업**: 시스템 변경 가능한 모든 도구 제한

#### **실제 사용 예시**

```
사용자: "이 React 컴포넌트의 성능 문제를 분석해줘"
Chatbot: "코드를 분석한 결과 3가지 문제점을 발견했습니다:
1. useEffect 의존성 배열 문제로 불필요한 리렌더링
2. 큰 객체의 얕은 복사로 인한 메모리 이슈
3. map 함수에서 key props 누락
각각에 대한 해결 방안을 제시해드릴까요?"
```

### **⚡ Agent Mode - 능동적 AI 개발 파트너**

#### **모든 기능 허용**

- ✅ **읽기 + 쓰기**: 파일 분석부터 수정까지 전체 과정
- ✅ **실행**: 빌드, 테스트, 서버 실행 등 명령어 수행
- ✅ **대화**: 작업 중 자연스러운 소통과 질문 가능

#### **실제 사용 예시**

```
사용자: "JWT 인증 시스템을 구현해줘"
Agent: "JWT 인증 시스템을 구현하겠습니다.

1. 먼저 필요한 라이브러리를 설치하겠습니다
   [execute_command 실행: npm install jsonwebtoken bcrypt]

2. 인증 미들웨어를 생성합니다
   [write_to_file: middleware/auth.js 생성]

3. 로그인 API 엔드포인트를 구현합니다
   [write_to_file: routes/auth.js 생성]

구현이 완료되었습니다. 테스트해보시겠어요?"
```

### **🛡️ 도구 제한 시스템 (Dual-Layer Security)**

Chatbot 모드의 안전성은 **이중 보안 레이어**로 구현됩니다:

#### **Layer 1: JSON 기반 프롬프트 필터링**

```json
// caret-src/core/prompts/sections/TOOL_DEFINITIONS.json
{
	"execute_command": {
		"mode_restriction": "agent_only" // Chatbot 모드 프롬프트에서 제외
	},
	"write_to_file": {
		"mode_restriction": "agent_only" // 파일 편집 도구 제외
	},
	"replace_in_file": {
		"mode_restriction": "agent_only" // 파일 수정 도구 제외
	}
}
```

#### **Layer 2: 실행시점 상수 기반 차단**

```typescript
// caret-src/shared/constants/ModeSystemConstants.ts
export const RESTRICTED_TOOLS = {
	CHATBOT_BLOCKED: ["write_to_file", "replace_in_file", "execute_command"] as const,
	AGENT_ALLOWED: "*" as const,
} as const
```

#### **핵심 컴포넌트**

- **`ModeSystemRegistry`**: 어댑터 패턴 기반 중앙 집중식 도구 제한 관리
- **`CaretToolHandler`**: JSON 기반 모드별 도구 필터링 (`isToolAllowed()`)
- **`CaretToolSelector`**: 지능형 도구 선택과 검증
- **`ToolExecutor.ts`**: 실행시점 이중 안전 검사

#### **검증된 이중 보안 체계**

- ✅ **Layer 1**: JSON 프롬프트에서 위험한 도구 제거 → LLM이 애초에 접근 불가
- ✅ **Layer 2**: 실행시점에서 추가 차단 → 만약의 경우 런타임 보호
- ✅ **Chatbot 모드**: 안전한 읽기 전용 도구만 사용 가능
- ✅ **Agent 모드**: 모든 도구 사용 가능 + 자유로운 대화
- ✅ **TDD 검증**: `ToolRestrictionIntegration.test.ts`로 42개 테스트 통과

#### **⚡ Agent Mode (AI 주도권)**

- **역할**: AI가 주도권을 가지고 **모든 개발 작업을 직접 수행**하는 자동화 모드
- **모든 기능 허용**:
    - ✅ **읽기**: 파일 분석 및 검토
    - ✅ **대화**: 질문과 설명
    - ✅ **브라우저**: 웹 검색 및 자료 조사
    - ✅ **실행**: 명령어 실행, 빌드, 테스트, 서버 실행
    - ✅ **수정**: 코드 작성, 파일 편집, 설정 변경
    - ✅ **삭제**: 불필요한 파일 정리, 코드 리팩토링
- **사용 시나리오**: 기능 구현, 버그 수정, 프로젝트 초기 설정, 자동화 작업

#### **🔄 Mode System 선택**

- **Caret System**: Chatbot/Agent 모드 사용 (새로운 직관적 인터페이스)
- **Cline System**: Plan/Act 모드 사용 (기존 Cline 사용자 호환성)
- **📝 JSON 기반 프롬프트**: 구조화된 707라인 프롬프트 대체 시스템

### **🎯 아키텍처 설계 원칙 (2025-08-25 최종판)**

#### **1. 머징 최적화 우선 (가장 중요)**

- **Cline 코드 비접촉**: 기존 CARET MODIFICATION 영역에서만 작업

- **어댑터 패턴**: Cline 로직 변경 없이 해석만 변경
- **타입 안전성**: 컴파일 타임에 모든 문자열 오류 감지

#### **2. 완전한 독립성 달성**

- **해석적 독립성**: 같은 `mode: "act"`도 시스템별로 다르게 해석
- **기능적 독립성**: Plan/Act 코드 변경이 Chatbot/Agent에 0% 영향
- **UI 독립성**: 사용자는 "Agent/Chatbot" 용어만 보고 "Plan/Act"는 숨김
- **의미론적 순수성**: Agent ≠ Act 혼동 방지

#### **3. 전진 호환성 보장**

- **자동 신기술 반영**: Cline 새 모드/도구가 Caret에서 즉시 사용 가능
- **Zero Maintenance**: 수동 업데이트 없이 발전사항 자동 상속
- **분류 알고리즘**: `classifyNewMode()`로 새 Cline 기능 자동 Agent/Chatbot 분류

#### **4. 개발자 경험 최적화**

- **IntelliSense**: 상수 기반 자동완성으로 생산성 향상
- **컴파일 타임 검증**: 런타임 오류 사전 차단
- **중앙 집중 관리**: 모든 모드 관련 로직이 2개 파일에 집중
- **TDD 검증**: 모든 변환 로직이 테스트로 보장

## 🎯 **사용 방법**

### **모드 전환**

1. **단축키로 빠른 전환**
    - `⌘⇧A` (macOS) 또는 `Ctrl+Shift+A` (Windows/Linux)
    - 현재 모드에서 반대 모드로 즉시 전환

2. **UI에서 수동 전환**
    - 채팅 입력창 상단의 모드 토글 버튼 클릭
    - 💬 Chatbot ↔ 🤖 Agent 아이콘으로 구분

3. **시스템 모드 선택**
    - 설정에서 Caret 모드 ↔ Cline 모드 전환 가능

#### **대화 흐름**

    }
