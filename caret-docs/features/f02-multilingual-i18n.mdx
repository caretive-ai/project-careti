# 다국어 i18n 시스템 (Multilingual i18n System)

Caret의 **다국어 지원 시스템**은 한국어, 영어, 일본어, 중국어 4개 언어를 중심으로 설계된 포괄적인 국제화(i18n) 시스템입니다.

## 📋 **기능 개요**

### **지원 언어**
- 🇰🇷 **한국어 (ko)**: 완전 번역 및 현지화 (조사 자동 처리 포함)
- 🇺🇸 **영어 (en)**: 기본 언어 및 fallback
- 🇯🇵 **일본어 (ja)**: 번역 지원
- 🇨🇳 **중국어 (zh)**: 번역 지원

### **네임스페이스 구조**
각 언어마다 **11개 이상의 네임스페이스**로 체계적으로 관리됩니다. 이를 통해 각 기능 영역별로 번역 리소스를 분리하여 유지보수성을 높입니다.

| 네임스페이스 | 용도 | 예시 키 |
|---|---|---|
| **common** | 공통 UI 요소 | `button.save`, `error.generic` |
| **chat** | 채팅 화면 관련 | `startNewTask`, `error.displayContent` |
| **welcome** | 환영 페이지 | `greeting`, `coreFeatures.header` |
| **settings** | 설정 페이지 | `tabs.apiConfiguration.name`, `settings.modeSystem.label` |
| **history** | 작업 기록 페이지 | `history`, `fuzzySearchPlaceholder` |
| **persona** | AI 페르소나 | 캐릭터 설명, 특성 |
| **models** | AI 모델 설명 | 모델 특성, 사용법 |
| **announcement** | 공지사항 | 업데이트, 알림 |
| **browser** | 브라우저 기능 | `checkingConnection`, `viewportSize` |
| **menu** | 메뉴 항목 | 메뉴 관련 텍스트 |
| **validate-api-conf**| API 검증 | 오류 메시지, 검증 안내 |

**참고**: 네임스페이스는 지속적으로 추가될 수 있으며, 현재 `en` 기준 11개의 네임스페이스가 존재합니다.

## 🏗️ **시스템 아키텍처**

### **파일 구조**
```
webview-ui/src/caret/
├── locale/                        # 다국어 JSON 파일
│   ├── en/ (11개)                 # 영어 (기준 언어)
│   ├── ko/ (7개+)                 # 한국어
│   ├── ja/ (8개+)                 # 일본어
│   └── zh/ (8개+)                 # 중국어
├── utils/
│   └── i18n.ts                    # 메인 i18n 유틸리티
├── hooks/
│   └── useCaretI18n.ts           # React i18n Hook
└── context/
    └── CaretI18nContext.tsx      # i18n Context Provider
```

### **핵심 API 및 사용법**

**1. 번역 함수 `t`**
가장 기본적인 번역 함수입니다. 컴포넌트 외부에서도 사용 가능합니다.

```typescript
import { t } from '@/caret/utils/i18n';

// 기본 사용법
t('button.save', 'common'); // -> "저장" 또는 "Save"

// 변수 삽입
t('message.welcome', 'common', { user: 'Luke' }); // -> "Luke님, 환영합니다."
```

**2. React Hook `useCaretI18n`**
React 컴포넌트 내에서 언어 변경 등의 인터랙티브한 기능을 사용할 때 유용합니다.

```typescript
import { useCaretI18n } from '@/caret/hooks/useCaretI18n';

function MyComponent() {
    const { t, currentLanguage, changeLanguage } = useCaretI18n();

    return (
        <div>
            <h1>{t("welcome.title", "welcome")}</h1>
            <button onClick={() => changeLanguage('ko')}>
                한국어로 변경
            </button>
        </div>
    );
}
```

### **한국어 조사 자동 처리**
Caret의 i18n 시스템은 한국어의 복잡한 조사를 자동으로 처리하여 자연스러운 문장을 생성합니다. (현재는 `ko-postposition` 라이브러리를 통해 구현되어 있지 않지만, 향후 확장될 수 있습니다.)

## 🧪 **테스트 및 검증**

### **수동 검증 절차**
1.  **UI 확인**: `npm run watch` 실행 후 VS Code에서 직접 각 페이지의 번역이 올바르게 표시되는지 확인합니다.
2.  **언어 전환**: 설정 페이지에서 언어를 변경했을 때 UI가 즉시 해당 언어로 변경되는지 확인합니다.

### **자동화 도구**
-   **네임스페이스 검증**: `npm run report:i18n-namespace` 명령어를 실행하여 `i18n.ts`에 등록 누락된 네임스페이스나, 언어별로 누락된 번역 파일을 검사합니다.
-   **키 누락 검증**: `npm run report:i18n-keys` 명령어를 실행하여 기준 언어(en)에 존재하는 키가 다른 언어 파일에 누락되었는지 확인합니다.
-   **키 자동 동기화**: `npm run sync:i18n-keys` 명령어를 실행하여 누락된 키를 자동으로 추가하고 영어(en)를 기본값으로 채웁니다.
-   **미사용 키 검증 (개발 예정)**: 코드에서 사용되지 않는 번역 키를 찾아냅니다.

## 🔄 **번역 추가 및 관리 프로세스**

1.  **네임스페이스 결정**: 추가할 번역이 기존 네임스페이스에 맞지 않으면 새로운 네임스페이스(`{namespace}.json`)를 생성합니다.
2.  **JSON 파일 수정**: `webview-ui/src/caret/locale/en/` 폴더에 기준이 될 영어 번역을 추가합니다.
3.  **다른 언어 파일 동기화**: `ko`, `ja`, `zh` 폴더의 해당 네임스페이스 파일에도 동일한 키를 추가하고 번역합니다.
4.  **네임스페이스 등록**: 새 네임스페이스를 생성한 경우, `webview-ui/src/caret/utils/i18n.ts` 파일의 `translations` 객체에 반드시 추가해야 합니다. **이 과정을 누락하는 것이 가장 흔한 실수입니다.**
5.  **코드 적용**: `t('your.key', 'your_namespace')` 형태로 코드에 적용합니다.
