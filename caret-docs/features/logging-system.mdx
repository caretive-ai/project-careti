# Logging System

Caret의 **로깅 시스템**은 백엔드와 프론트엔드를 통합한 포괄적인 개발 디버깅 및 모니터링 시스템입니다.

## 📋 **기능 개요**

### **통합 로깅 아키텍처**

- **백엔드/프론트엔드 통합**: 일관된 로그 형식으로 전체 시스템 추적
- **카테고리별 분류**: 기능별/심각도별 체계적 로그 관리
- **개발 디버깅 지원**: 상세한 오류 추적 및 성능 모니터링
- **실시간 로그 스트리밍**: 개발 중 실시간 로그 확인

### **차별화 포인트**

- **Cline 독립적**: Cline 원본 로깅과 병행 사용 가능
- **VSCode 통합**: Extension Host와 Webview 양쪽 로깅
- **성능 최적화**: 프로덕션에서는 최소 오버헤드
- **타입 안전성**: TypeScript 기반 타입 안전한 로깅

### **백엔드 로거 (Extension Host)**

```typescript
// caret-src/utils/caret-logger.ts
export interface LogLevel {
	ERROR: 0
	WARN: 1
	INFO: 2
	DEBUG: 3
}

export interface LogCategory {
	INIT: "INIT"
	AUTH: "AUTH"
	MODE_CHECK: "MODE_CHECK"
	API: "API"
	FILE_OP: "FILE_OP"
	GENERAL: "GENERAL"
}

class CaretLogger {
	private static instance: CaretLogger
	private logLevel: number = 2 // INFO level
	private context: string = "[CARET-BACKEND]"

	static getInstance(): CaretLogger {
		if (!this.instance) {
			this.instance = new CaretLogger()
		}
		return this.instance
	}

	info(message: string, category: string = "GENERAL"): void {
		this.log(2, "INFO", message, category)
	}

	warn(message: string, category: string = "GENERAL"): void {
		this.log(1, "WARN", message, category)
	}

	error(message: string, category: string = "GENERAL"): void {
		this.log(0, "ERROR", message, category)
	}

	debug(message: string, category: string = "GENERAL"): void {
		this.log(3, "DEBUG", message, category)
	}

	private log(level: number, levelName: string, message: string, category: string): void {
		if (level <= this.logLevel) {
			const timestamp = new Date().toISOString()
			const formatted = `${timestamp} ${this.context} [${levelName}] [${category}] ${message}`

			if (level === 0) {
				console.error(formatted)
			} else if (level === 1) {
				console.warn(formatted)
			} else {
				console.log(formatted)
			}
		}
	}
}

export const caretLogger = CaretLogger.getInstance()
```

```typescript
export default class WebviewLogger {

	}

	}

	private log(level: number, levelName: string, message: string, ...args: any[]): void {
		if (level <= this.logLevel) {
			const timestamp = new Date().toISOString()
			const formatted = `${timestamp} ${this.context} [${levelName}] ${message}`

			if (level === 0) {

			} else if (level === 1) {

			} else {
				console.log(formatted, ...args)
			}
		}
	}
}
```

## 🎯 **사용 패턴 및 예시**

### **백엔드 사용 예시**

```typescript
// src/core/controller/index.ts
import { caretLogger } from "../../../caret-src/utils/caret-logger"

export class Controller {
    constructor(...) {
        caretLogger.info(`Controller constructor called. ID: ${this.id}`, "INIT")
        caretLogger.debug("Extension context loaded", "INIT")
    }

    async handleAuthCallback(customToken: string, apiKey: string) {
        try {
            caretLogger.info("[AUTH] handleAuthCallback started.", "AUTH")

            await storeSecret(this.context, "caretApiKey", apiKey)
            caretLogger.info("[AUTH] API key stored successfully.", "AUTH")

        } catch (error) {
            caretLogger.error(`[AUTH] Failed to handle auth callback: ${error}`, "AUTH")
        }
    }
}

// src/core/task/index.ts
async *attemptApiRequest(previousApiReqIndex: number): ApiStream {

    caretLogger.info(
        `🔍 [MODE-CHECK-CARET] Caret 모드 - SYSTEM_PROMPT 호출: mode=${this.chatSettings.mode}`,
        "MODE_CHECK"
    )
}
```

## 📊 **로그 카테고리 및 레벨**

### **카테고리별 분류**

| 카테고리       | 용도              | 예시                         |
| -------------- | ----------------- | ---------------------------- |
| **INIT**       | 초기화 및 설정    | Extension 시작, 설정 로드    |
| **AUTH**       | 인증 및 계정      | 로그인, API 키 관리          |
| **MODE_CHECK** | 모드 시스템       | Chatbot/Agent 모드 전환      |
| **API**        | 외부 API 호출     | AI 모델 요청, Caret API      |
| **FILE_OP**    | 파일 작업         | 파일 읽기/쓰기, 규칙 로딩    |
| **UI**         | 사용자 인터페이스 | 컴포넌트 렌더링, 이벤트      |
| **PERSONA**    | 페르소나 시스템   | 페르소나 선택, 프롬프트 변경 |
| **I18N**       | 다국어 시스템     | 언어 변경, 번역 로딩         |

```typescript
// 성능 측정을 위한 로깅
class PerformanceLogger {
	static startTimer(operation: string): string {
		const id = `${operation}-${Date.now()}`
		logger.debug(`⏱️ [PERF] Started: ${operation}`, "PERFORMANCE")
		return id
	}

	static endTimer(timerId: string): void {
		const duration = Date.now() - parseInt(timerId.split("-")[1])
		logger.info(`⏱️ [PERF] Completed in ${duration}ms`, "PERFORMANCE")
	}
}
```
