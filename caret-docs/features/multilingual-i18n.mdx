# Multilingual i18n System

Caret의 **다국어 지원 시스템**은 한국어, 영어, 일본어, 중국어 4개국을 완전 지원하는 포괄적인 국제화 시스템입니다.

## 📋 **기능 개요**

### **지원 언어**

- 🇰🇷 **한국어 (ko)**: 완전 번역 및 현지화
- 🇺🇸 **영어 (en)**: 기본 언어 및 fallback
- 🇯🇵 **일본어 (ja)**: 완전 번역 및 현지화
- 🇨🇳 **중국어 (zh)**: 완전 번역 및 현지화

### **네임스페이스별 분류**

각 언어마다 **7개 네임스페이스**로 체계적 관리:

| 네임스페이스          | 용도         | 파일 개수 | 예시                    |
| --------------------- | ------------ | --------- | ----------------------- |
| **common**            | 공통 UI 요소 | 4개       | 버튼, 메뉴, 일반 메시지 |
| **welcome**           | 환영 페이지  | 4개       | 온보딩, 시작 가이드     |
| **persona**           | AI 페르소나  | 4개       | 캐릭터 설명, 특성       |
| **settings**          | 설정 페이지  | 4개       | 옵션, 구성 항목         |
| **validate-api-conf** | API 검증     | 4개       | 오류 메시지, 검증 안내  |
| **announcement**      | 공지사항     | 4개       | 업데이트, 알림          |
| **models**            | AI 모델 설명 | 4개       | 모델 특성, 사용법       |

**총 파일 수**: **30개 JSON 파일** (7 네임스페이스 × 4 언어 + 추가 확장)

### **핵심 로직**

```typescript
// webview-ui/src/caret/utils/i18n.ts
export interface I18nConfig {
	language: "ko" | "en" | "ja" | "zh"
	namespace: "common" | "welcome" | "persona" | "settings" | "validate-api-conf" | "announcement" | "models"
	fallback: "en" // 번역 누락 시 영어로 fallback
}

// 번역 함수
export function t(key: string, namespace: string, language?: string): string {
	const lang = language || getCurrentLanguage()
	const translations = loadNamespace(namespace, lang)

	return (
		translations[key] ||
		loadNamespace(namespace, "en")[key] || // fallback
		key
	) // 최후 방안
}

// 사용 예시
t("account.signUpWithCaret", "common") // → "Sign up with Caret"
t("persona.ohSarang.description", "persona") // → "K-pop idol assistant"
```

### **동적 언어 로딩**

```typescript
// 성능 최적화: 필요한 언어+네임스페이스만 로딩
const loadNamespace = async (namespace: string, language: string) => {
    const module = await import(`../locale/${language}/${namespace}.json`)
    return module.default
}

// React 컴포넌트에서 사용
import { useCurrentLanguage } from '@/caret/hooks/useCurrentLanguage'

function MyComponent() {
    const { currentLanguage, setLanguage } = useCurrentLanguage()

    return (
        <button onClick={() => setLanguage('ko')}>
            {t("ui.changeLanguage", "common")}
        </button>
    )
}
```

## 📊 **번역 품질 및 관리**

### **번역 품질 기준**

- **정확성**: 원문의 의미 정확한 전달
- **일관성**: 용어 및 톤앤매너 일관성 유지
- **자연스러움**: 각 언어의 자연스러운 표현
- **기술 용어**: 개발 관련 용어의 적절한 번역/음차

### **번역 관리 프로세스**

```bash
# 1. 새로운 키 추가 시
# 모든 언어 파일에 동일한 키 구조로 추가

# 2. 번역 검증
# 각 언어별 네이티브 스피커 검토

# 3. 자동화 도구
npm run i18n:validate    # 키 일관성 검증
npm run i18n:missing     # 누락된 번역 찾기
npm run i18n:unused      # 사용되지 않는 키 찾기
```
