## ✨ 나만의 AI 코딩 파트너, Caret

Caret는 텍스트 커서(cursor)에서 이름을 가져온 AI 코딩 파트너입니다. 강력한 오픈소스 Cline 기반 위에 무료 크레딧, 듀얼 모드, 페르소나, 한국 특화 모델, 개선된 시스템 프롬프트/UX를 더했고, 개인 사용 경험을 지키면서도 기업 전용 커스터마이징을 지원하며 기업 AI 전환(AX) 기준을 만족시키는 AI 네이티브 코딩 플랫폼을 목표로 발전하고 있습니다.

**바로 시작하기**
- **Caret 설치하기**: [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=caretive.caret)
- **비즈니스 문의**: support@caret.team
- **핵심 키워드**: Cline 100% 호환 · 오픈소스/BYOK · 듀얼 모드 · 매월 무료 크레딧
