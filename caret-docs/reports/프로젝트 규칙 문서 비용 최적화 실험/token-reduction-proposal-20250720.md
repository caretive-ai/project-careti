# 연구 제안서: AI 컨텍스트 최적화를 위한 문서의 JSON 변환 효과 분석

## 1. 개요

본 문서는 프로젝트 내의 비정형 마크다운 문서들을 AI에 최적화된 정형 JSON 데이터로 변환했을 때, AI의 컨텍스트 이해에 필요한 토큰 비용이 얼마나 절감되는지를 정량적으로 분석하고, 이를 통해 AI 협업의 효율성 및 비용 절감 효과를 증명하는 것을 목표로 합니다.

## 2. 분석 계획 (Phase 1: 대상 문서 식별)

- **탐색 대상:** `.md`, `.mdx` 확장자를 가진 마크다운 문서
