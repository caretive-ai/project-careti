# Task 025: AI 컨텍스트 최적화를 위한 문서의 JSON 변환 연구

## 1. 목표

프로젝트 관련 한글 마크다운 문서를 AI에 최적화된 영문 JSON 형식으로 변환하여, AI의 컨텍스트 이해 비용(토큰)을 절감하고 성능을 향상시키는 방법론을 연구하고 그 효과를 정량적으로 증명합니다.

## 2. 배경

- **현황:** 대부분의 프로젝트 문서는 비정형적인 마크다운 형식이므로, AI가 이를 이해하기 위해 높은 토큰 비용을 소모하며, 이는 비효율과 오해의 소지가 있습니다.
- **제안 해결책:** 사람이 관리하는 원본 마크다운과 AI가 소비하는 최적화된 JSON 문서를 병렬로 운영하는 '듀얼 다큐멘테이션 시스템'을 구축합니다.

## 3. 주요 활동 계획 (연구 제안서 기반)

### Phase 1: 대상 문서 식별 및 기준 토큰 측정
1.  **탐색 시작점:** `.caretrules` 파일을 시작으로, 참조된 모든 마크다운(`.md`, `.mdx`) 문서를 탐색합니다.
2.  **재귀적 탐색:** 문서 내에 링크된 다른 문서들을 포함, 모든 깊이(depth)의 참조 문서를 재귀적으로 탐색하여 전체 목록을 생성합니다.
3.  **기준 토큰 측정:** 식별 과정에 소요된 총 토큰과, 식별된 모든 원본 문서의 총 토큰 양을 측정하여 기록합니다.

### Phase 2: AI 기반 JSON 변환 및 토큰 감소량 측정
1.  **파일명 생성 규칙:** 변환 대상 파일은 다음 규칙에 따라 명명합니다.
    - `{filename}.md` → `{filename}.json.md`
    - `{filename}.mdx` → `{filename}.json.mdx`
2.  **AI 기반 변환:** Phase 1에서 식별된 각 문서를 AI를 이용해 핵심 의미를 추출한 영문 JSON 형식으로 변환합니다.
3.  **참조 링크 변환:** 변환된 JSON 문서 내의 다른 문서 참조 링크 또한 위의 파일명 생성 규칙에 맞게 수정합니다.
4.  **토큰 감소량 측정:** 변환된 모든 JSON 문서의 총 토큰 양을 측정하고, 원본 문서 대비 총 토큰 감소량을 계산합니다.

### Phase 3: 시나리오 기반 예상 효과 보고서 작성
1.  **시나리오 선정:** "신규 AI가 프로젝트 아키텍처 파악하기"와 같은 구체적인 시나리오를 설정합니다.
2.  **예상 토큰 계산:** 해당 시나리오 수행에 필요한 문서 목록을 기반으로, 기존 방식(Markdown)과 제안 방식(JSON)의 예상 소요 토큰을 각각 계산하고 비교 분석합니다.
3.  **보고서 작성:** 연구의 타당성을 증명하기 위해, 시나리오 기반의 예상 토큰 절감 효과를 명시한 보고서를 작성합니다. (의미론적 검증은 향후 과제로 남겨둡니다.)

## 4. 결과물

- AI 기반 변환 프로세스 정의서 및 프롬프트 예시.
- **시나리오 기반 예상 토큰 절감 효과 분석 보고서.**
- 연구 결과를 바탕으로 한 연구 제안서 초안.

## 5. 궁극적 목표: 자동화된 '프로젝트 시스템 프롬프트' 생성 AI 개발

- **최종 비전:** 프로젝트를 자동으로 분석하여, 그 구조와 개발 방법론의 정수를 AI에게 효과적으로 전달하는 **'의미를 담은 프로젝트 시스템 프롬프트'**를 생성하는 것을 목표로 합니다.
- **장기 과제:** 이 '프로젝트 시스템 프롬프트' 생성을 전담하는 특화 AI 모델을 개발하여, AI가 스스로 프로젝트의 맥락을 파악하고 작업에 임하도록 하는 것입니다.
