# Caret 로컬 빌드 및 설치 가이드

이 문서는 Caret VSCode 확장의 로컬 빌드 결과물(`.vsix` 파일)을 설치하는 방법을 안내합니다.

## 설치 방법

생성된 `.vsix` 파일을 사용하여 로컬 환경에 Caret 확장을 설치할 수 있습니다.

1.  **VSCode 확장 뷰 열기:**
    *   VSCode의 왼쪽 사이드바에서 확장 아이콘(네모 4개 모양)을 클릭하거나, 단축키 `Ctrl+Shift+X`를 누릅니다.

2.  **VSIX 파일 설치:**
    *   확장 뷰 상단의 `...`(추가 작업) 메뉴를 클릭합니다.
    *   드롭다운 메뉴에서 `VSIX에서 설치...`를 선택합니다.
    *   파일 탐색기가 열리면, 빌드한 `.vsix` 파일을 찾아 선택하고 설치 버튼을 클릭합니다.

3.  **VSCode 다시 로드 (필요 시):**
    *   설치가 완료된 후 VSCode를 다시 로드하라는 알림이 표시될 수 있습니다. 안내에 따라 VSCode를 다시 시작하면 설치된 확장이 활성화됩니다.

이제 로컬에서 빌드된 최신 버전의 Caret 확장을 사용할 수 있습니다.
