# 잔여 작업 실행 계획 (Phase D/E/F)

마스터로부터 전달받은 잔여 일감을 바탕으로 구체적인 실행 계획을 수립합니다.

## 1. D-1: ModeSystem TDD 및 검증 (우선순위: 높음)
- **목표**: ModeSystem의 동작(Caret/Cline 분기, 영속화)을 테스트 코드로 입증하고 빌드/테스트를 통과시킨다.
- **세부 작업**:
  - [ ] `caret-src/__tests__/prompt-system/mode-system.test.ts` 등 관련 테스트 파일 확인 및 보강.
  - [ ] `npm run compile` 실행 (전체 컴파일).
  - [ ] `npm run test` 실행 (단위 테스트).
  - [ ] E2E 테스트 커버리지 검토 (필요 시 Playwright 테스트 케이스 추가).

## 2. D-2: CLI 완성 및 브랜딩 (우선순위: 높음)
- **목표**: Caret CLI의 브랜딩, 서버 연동, 패키징을 완료하여 배포 가능한 상태로 만든다.
- **세부 작업**:
  - [ ] **서버 연동**: `auth` 명령어의 실제 API 연동 테스트 및 디버깅.
  - [ ] **브랜딩/배너**: CLI 배너, 도움말 메시지, 프롬프트 등이 Caret 브랜드로 일관되게 표시되는지 확인.
  - [ ] **패키징**: `cli-caret` 패키징 스크립트 검증 및 `standalone` 모듈 포함 여부 확인.
  - [ ] **감지/설치**: VS Code 확장에서 CLI 설치 감지 및 자동 설치 유도 로직 검증.

## 3. 문서 및 피처 번호 재정렬 (Phase E)
- **목표**: 기능 변경 사항을 문서에 반영하고 혼란을 방지한다.
- **세부 작업**:
  - [ ] 피처 번호 스왑 (F05 ↔ F04) 및 참조 링크 업데이트.
  - [ ] `features/index.md`, `README.md`, `CHANGELOG.md` 업데이트.
  - [ ] 다국어 문서 동기화.

## 4. 회귀 검증 및 자동화 (Phase F)
- **목표**: 기존 기능의 정상 동작을 보장하고 누락을 방지한다.
- **세부 작업**:
  - [ ] CLI 설치/감지/배너/프롬프트 수동 테스트 시나리오 수행.
  - [ ] `npm run compile`, `npm run test` 재수행.
  - [ ] `scripts/compare-with-cline.mjs` 작성 및 실행 (누락 파일 감지).
  - [ ] PR 체크리스트에 자동화 스크립트 실행 결과 포함.
