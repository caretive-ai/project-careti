```typescript
// Task 완료 이벤트 리스너 추가
function waitForTaskCompletion(taskId: string): Promise<void> {
  return new Promise((resolve) => {
    const checkInterval = setInterval(async () => {
      const state = await controller.getTaskState(taskId)
      if (state.isComplete || state.isError) {
        clearInterval(checkInterval)
        resolve()
      }
    }, 1000)
  })
}
```

#### Subagent 포트 충돌 문제 해결
**문제**: VS Code Extension에서 `caret "prompt"` 실행 시 포트 충돌
```
Error: EADDRINUSE: address already in use 127.0.0.1:26040
```

**원인 분석 결과**:
1. Extension이 포트 26040 (ProtoBus), 26041 (HostBridge) 사용 중
2. Subagent 명령 실행 시 `enhanced-terminal.js`가 shell 명령으로 `caret "..."` 실행
3. `bin/caret` 스크립트가 새 `node cline-core.js` 프로세스 spawn
4. 새 프로세스가 동일 포트(26040, 26041) 바인딩 시도 → **충돌**

**실행 흐름**:
```
executeCommandTool → StandaloneTerminalManager
  → spawn("bash", ["-l", "-c", "caret \"task\""])
    → bin/caret → spawn("node", ["cline-core.js", "task"])
      → startHostBridgeServer() (port 26041)
      → startProtobusService() (port 26040)
        → ❌ EADDRINUSE
```

**해결 방법**: Subagent 모드에서 별도 포트 사용
- ✅ `executeCommandTool`에서 Subagent 감지 시 환경변수 설정
- ✅ `cline-core.ts`에서 Subagent 모드 감지 및 별도 포트 사용

**수정 파일**:
1. `src/core/task/index.ts` (Line 1060-1064)
   ```typescript
   // Set environment variables for Subagent to use different ports
   globalThis.process.env.CARET_SUBAGENT_MODE = "true"
   globalThis.process.env.CARET_SUBAGENT_PROTOBUS_PORT = "26050"
   globalThis.process.env.CARET_SUBAGENT_HOSTBRIDGE_PORT = "26051"
   ```

2. `src/standalone/cline-core.ts` (Line 45-52)
   ```typescript
   // Check for Subagent mode to use different ports
   const isSubagentMode = process.env.CARET_SUBAGENT_MODE === "true"
   if (isSubagentMode) {
     log("🔧 Running in Subagent mode - using dedicated ports to avoid conflicts")
     process.env.PROTOBUS_ADDRESS = `127.0.0.1:26050`
     process.env.HOST_BRIDGE_ADDRESS = `127.0.0.1:26051`
   }
   ```

- Subagent: 26050 (ProtoBus), 26051 (HostBridge)
