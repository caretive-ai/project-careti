## 🔧 구체적 실행 방법

### **파일 교체 프로세스**
```bash
# 1. 현재 파일 백업 (git으로 관리되므로 선택사항)
cp ChatRow.tsx ChatRow.tsx.backup

# 2. caret-main 버전으로 교체
cp /d/dev/caret/caret-main/webview-ui/src/components/chat/ChatRow.tsx \
   /d/dev/caret-merging/webview-ui/src/components/chat/ChatRow.tsx

# 3. 컴파일 및 테스트
npm run compile
npm run test:webview

# 4. 필요 시 수동 조정 (import 경로, 의존성 등)
```

1. **의존성 확인**: caret-main과 caret-merging 간 package.json 차이

3. **타입 정의**: TypeScript 인터페이스 호환성
4. **스타일링**: styled-components 의존성 확인
