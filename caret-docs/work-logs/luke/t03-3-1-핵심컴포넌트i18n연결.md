## 🔧 구체적 실행 방법

### **i18n 구체 전업 프로세스**
```bash
# 1. caret-main에서 locale 파일들 복사
cp -r /d/dev/caret/caret-main/webview-ui/src/caret/locale \
      /d/dev/caret-merging/webview-ui/src/caret/

# 2. i18n 유틸리티 복사 및 수정
cp /d/dev/caret/caret-main/webview-ui/src/caret/utils/i18n.ts \
   /d/dev/caret-merging/webview-ui/src/caret/utils/

# 3. 컴포넌트별 하드코딩 텍스트 i18n 적용
# 예: ChatRow.tsx에서 "Cline wants..." -> t("chat.executeCommand", "common")

# 4. 컴파일 및 테스트
npm run compile
npm run test:webview
```

### **주의사항**
1. **의존성 확인**: caret-main과 caret-merging 간 package.json 차이
2. **import 경로**: @/ 경로 별칭 일관성 확인
3. **타입 정의**: TypeScript 인터페이스 호환성
4. **스타일링**: styled-components 의존성 확인
