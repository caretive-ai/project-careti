## [0.4.8] 2026-02-13

> **Примечание**: Careti v0.4.8 вводит систему очереди сообщений в стиле Claude Code и исправляет проблему бесконечной загрузки v0.4.7.

### ✨ Новые функции
- **F19 Система очереди сообщений**: Вводите следующие инструкции, пока ИИ выполняет стриминг. Ввод в очереди отображается как встроенный предпросмотр над полем ввода.
- **Мгновенная отмена ESC**: Одно нажатие ESC немедленно останавливает стриминг и восстанавливает ввод из очереди в редактор для редактирования перед повторной отправкой.
- **Встроенное редактирование/удаление очереди**: Кнопки редактирования (восстановить в поле ввода) и удаления (отменить) в предпросмотре ожидающего ввода.
- **Режим агента/чатбота CLI**: Независимые режимы агента и чатбота для CLI с поддержкой headless/yolo, переподключением EOF и улучшенной обработкой ввода.
- **Телеметрия CLI**: Отслеживание событий на основе PostHog для аналитики использования CLI.
- **E2E-тесты CLI**: E2E-тесты для режима агента, поведения CLI, вывода и интерактивного режима.
- **RPC clearPendingInput**: Новый gRPC-эндпоинт для очистки ввода в очереди через кнопки редактирования/удаления.

### ✨ Улучшения
- **Параллельный опрос feature flags**: Последовательное получение флагов (14 запросов) заменено на параллельное с общим таймаутом 5 секунд.
- **Неблокирующая инициализация**: `featureFlagsService.poll()` изменён на fire-and-forget, чтобы не блокировать активацию расширения.
- **Паттерн команд субагента**: Добавлен CARETI_COMMAND_PATTERN для поддержки субагента CLI careti/cline.

### Исправления
- **Бесконечная загрузка v0.4.7**: `featureFlagsService.poll()` блокировал инициализацию расширения, когда `data.cline.bot` был недоступен. Изменён на неблокирующий с таймаутом.
- **Миграция ApiProvider**: Добавлена миграция `"caret"` → `"careti"` для пользователей, обновляющихся с v0.4.6, у которых в сохранённых настройках оставалось старое имя провайдера.
- **Фолбэк обработчика API**: Добавлен `case "caret":` фолбэк в switch провайдера API для корректной обработки немигрированных значений провайдера.
- **Вызов legacy-миграции**: `migrateLegacyApiConfigurationToModeSpecific()` был определён, но никогда не вызывался при инициализации. Теперь корректно вызывается.
- **Race condition pendingInput**: Исправлен вызов `consumePendingInput` после `cancelTask()`, который уже уничтожил сессию через `sessionManager.delete()`.
- **Очистка отладочных логов**: Удалены консольные логи `[CORE-DEBUG]`, `[CLI-DEBUG]`, `[GLM4.7-DEBUG]`.

## [0.4.5] 2026-01-18

> **Примечание**: Careti v0.4.5 интегрирует систему Skills, Hooks i18n и другие функции из Cline v3.49.0+ через cherry-pick.

### ✨ Новые функции
- **Полная поддержка Z.AI GLM-4.7**: Поддерживает режим Thinking и естественный стиль разговора.
- **Провайдер [Upstage](https://upstage.ai/)**: Новый провайдер с поддержкой моделей Upstage Solar.
- **Инструменты изображений для текстовых моделей**: Текстовые модели теперь могут использовать инструменты аккаунта Careti для генерации и анализа изображений.
- **Система Skills** (cherry-pick Cline v3.49.0+): Определяйте специфичные для проекта навыки, которые ИИ может использовать. Управляйте навыками в каталогах `.agents/skills/` или `.users/skills/`.
- **Система Hooks** (cherry-pick Cline v3.49.0+): Выполняйте пользовательские скрипты до/после выполнения инструментов. Управляйте хуками в каталогах `.agents/hooks/` или `.users/hooks/`.
- **Архитектура двойного каталога & /init**: Токен-оптимизированный контекст ИИ (`.agents/`) и документы пользователя (`.users/`) с политикой зеркалирования 1:1. Используйте команду `/init` для анализа проекта и автоматической генерации файлов контекста. AGENTS.md и CLAUDE.md служат стандартными точками входа.
- **Поддержка документов HWP**: Кроссплатформенная поддержка парсинга HWP для Windows, macOS и Linux.
- **Инструмент read_document**: Унифицированный инструмент чтения документов с поддержкой HWP, PDF, DOCX, PPTX и других. Включает определение устаревшего формата PPT.
- **Инструмент analyze_image**: Новый инструмент анализа изображений, интегрированный с Gemini аккаунта Careti. Максимальный лимит 7500px, включает руководства по отчётам анализа.
- **Улучшения инструмента generate_image**: Поддержка парсинга XML-тегов `<image>`, поддержка путей к файлам (относительных/абсолютных), руководства по пропуску aspect_ratio/image_size.
- **Переключатель отправки изображений**: Функция переключения отправки файлов изображений через @упоминание.

### ✨ Улучшения
- **Расширение языков**: Добавлены французский, немецкий и русский переводы. Приоритет странам с собственными моделями ИИ (Mistral, Aleph Alpha, Yandex и др.).
- **Флаги стран провайдеров**: Отображение флагов стран для провайдеров (перспектива Sovereign Cloud).
- **Изменение глобального пути контекста**: Путь глобальных настроек агента изменён на `~/Documents/.agents/`.
- **Поддержка i18n**: Добавлены корейский, японский и китайский переводы для функций Hooks и Skills.
- **Парсинг YAML frontmatter**: Добавлена общая утилита парсинга YAML для Skills/Hooks.
- **Провайдер по умолчанию**: Новые пользователи теперь имеют Careti как провайдера по умолчанию.
- **Управление UI через Feature Config**: Управление UI аккаунта/режима/диктовки через feature config.
- **Оптимизация размера VSIX**: Уменьшение размера расширения за счёт исключения бинарных файлов iOS/Android.
- **UI настроек изображений**: UI настроек соотношения сторон/разрешения изображений теперь виден для всех провайдеров.

### Исправления
- **Ошибка активации sharp**: Исправлена ошибка активации библиотеки обработки изображений.
- **Обработка ссылок на изображения**: Исправлены проблемы обработки и оптимизации ссылок на изображения.
- **Дублирование сообщений**: Исправлено двойное появление сообщения "Requesting Careti image generation".
