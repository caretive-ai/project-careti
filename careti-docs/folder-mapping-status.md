# 문서 언어 정합 현황

## 기준
- `careti-docs/`는 **한국어 문서**가 기본입니다.
- 영어 문서는 `.en` 접미사를 사용하거나 `features.en/**`에 둡니다.
- `docs/`는 Cline 원문(영문)이라 편집하지 않습니다.
- `docs.careti.ai/`는 배포용 다국어 문서입니다.

## 현재 정합 상태
- `development/`, `guides/`, `user-guide/`, `system-prompts-ko/`는 한국어 기준으로 유지
- `features.en/`는 영문 기능 스펙 전용
- 한국어 문서 내부의 영문 섹션/헤더 혼용은 순차 정리 중

## 진행 체크리스트

- [ ] 영어 문서에 `.en` 접미사 적용 여부 점검
- [ ] 기능 스펙은 `features.en/**`로 통일 확인
