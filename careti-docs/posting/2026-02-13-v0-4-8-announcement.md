Careti v0.4.8은 **AI 응답을 기다리는 동안에도 다음 지시를 미리 입력**할 수 있는 메시지 큐 시스템과, **ESC 한 번으로 스트리밍을 즉시 중단**하는 기능을 도입합니다. v0.4.7에서 발생했던 무한 로딩 문제도 해결되었습니다.


## 주요 업데이트


### 📨 메시지 큐 시스템 (Claude Code 스타일)

AI가 응답하는 동안에도 다음 지시를 입력할 수 있습니다. 입력한 내용은 입력창 위에 **미리보기**로 표시되어, AI 응답이 끝나면 자동으로 전송됩니다.

- 스트리밍 중에도 다음 작업 지시를 미리 타이핑
- 대기 중인 메시지를 미리보기에서 바로 **편집** 또는 **삭제**
- 여러 작업을 연속으로 지시할 때 대기 시간 제로


### ⚡ ESC 즉시 취소

AI 응답이 원하는 방향이 아닐 때, **ESC 키 한 번**으로 스트리밍을 즉시 중단합니다.

- 대기 중인 입력이 있으면 편집기로 자동 복원
- 수정 후 바로 재전송 가능
- 마우스 없이 키보드만으로 빠른 작업 흐름 유지


### 🤖 CLI 에이전트/챗봇 모드

Careti CLI에 독립적인 에이전트 모드와 챗봇 모드가 추가되었습니다.

- `careti "prompt"` — 한 줄로 서브에이전트 실행 (headless/yolo 지원)
- EOF 재연결로 세션 안정성 향상
- PostHog 기반 사용 분석 텔레메트리
- Agent/Chatbot/Interactive 모드 E2E 테스트 커버리지


### 🔧 v0.4.7 무한 로딩 수정

v0.4.7에서 `data.cline.bot` 서버에 접속이 안 될 경우 확장이 시작되지 않는 문제를 해결했습니다.

- 기능 플래그 폴링을 논블로킹으로 전환 (14개 요청 병렬화, 5초 타임아웃)
- `caret` → `careti` 프로바이더명 자동 마이그레이션 (v0.4.6 → v0.4.8 업그레이드 시)
