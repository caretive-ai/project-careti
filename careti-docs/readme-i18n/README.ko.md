## 🎉 v0.4.8

- 📨 **메시지 큐 시스템** — AI 응답 중에도 다음 지시를 입력, 대기 중인 입력이 미리보기로 표시
- ⚡ **ESC 즉시 취소** — ESC 한 번으로 스트리밍 중단, 대기 입력이 편집기로 복원
- 🖊️ **대기 메시지 편집/삭제** — 미리보기에서 바로 대기 메시지 수정 또는 삭제
- 🤖 **CLI 에이전트/챗봇 모드** — 헤드리스/yolo 모드, 텔레메트리, E2E 테스트, EOF 재연결
- 🔧 **무한 로딩 수정** — 논블로킹 기능 플래그 폴링, `caret→careti` 프로바이더 마이그레이션

## 📁 이중 디렉토리 & /init

**토큰 최적화 AI 컨텍스트 + 사용자 언어 문서를 1:1 미러링으로 관리**

```
.agents/                    # AI용 (영어, 토큰 최적화)
├── context/agents-rules.json  # 규칙 SoT
├── workflows/              # 작업 워크플로우
├── skills/                 # AI 스킬
└── hooks/                  # 자동화 훅

.users/                     # 사용자용 (사용자 언어)
├── context/agents-rules.md   # 상세 설명
├── workflows/              # (.agents/ 미러링)
├── skills/                 # (.agents/ 미러링)
└── hooks/                  # (.agents/ 미러링)
```

- **`/init`**: 프로젝트 분석 후 컨텍스트 파일 자동 생성
- **1:1 미러링**: `.agents/` ↔ `.users/` 변경사항 동기화 유지
- **AGENTS.md / CLAUDE.md**: 컨텍스트 연결 표준 진입점

## 🛠️ 이미지/문서 도구

텍스트 전용 모델에서도 Careti 계정으로 사용 가능합니다.

- **generate_image** — 이미지 생성 (Nano Banana)
- **analyze_image** — 이미지 분석 (Gemini)
- **read_document** — HWP, PDF, DOCX, PPTX 읽기
