## 🎉 v0.4.8

- 📨 **Очередь сообщений** — Вводите следующие инструкции во время стриминга ИИ, очередь отображается в превью
- ⚡ **Мгновенная отмена ESC** — Одно нажатие ESC останавливает стриминг и восстанавливает ввод в редакторе
- 🖊️ **Редактирование/удаление очереди** — Редактируйте или удаляйте сообщения в очереди прямо из превью
- 🤖 **CLI режим агента/чатбота** — Headless/yolo режим, телеметрия, E2E тесты, EOF реконнект
- 🔧 **Исправление бесконечной загрузки** — Неблокирующий опрос флагов, миграция провайдера `caret→careti`

## 📁 Двойной каталог & /init

**Токен-оптимизированный контекст ИИ + Документы пользователя с политикой зеркалирования 1:1**

```
.agents/                    # Для ИИ (английский, оптимизация токенов)
├── context/agents-rules.json  # Правила SoT
├── workflows/              # Рабочие процессы задач
├── skills/                 # Навыки ИИ
└── hooks/                  # Хуки автоматизации

.users/                     # Для пользователя (язык пользователя)
├── context/agents-rules.md   # Подробное объяснение
├── workflows/              # (зеркало .agents/)
├── skills/                 # (зеркало .agents/)
└── hooks/                  # (зеркало .agents/)
```

- **`/init`**: Анализирует проект и автоматически генерирует файлы контекста
- **Зеркалирование 1:1**: Изменения `.agents/` ↔ `.users/` остаются синхронизированными
- **AGENTS.md / CLAUDE.md**: Стандартные точки входа, связанные с контекстом

Доступны через аккаунт Careti даже для текстовых моделей.

- **generate_image** — Генерация изображений (Nano Banana)
- **analyze_image** — Анализ изображений (Gemini)
- **read_document** — Чтение HWP, PDF, DOCX, PPTX
