## 📁 双目录 & /init

**令牌优化的AI上下文 + 用户语言文档采用1:1镜像管理**

```
.agents/                    # AI用（英语，令牌优化）
├── context/agents-rules.json  # 规则SoT
├── workflows/              # 任务工作流
├── skills/                 # AI技能
└── hooks/                  # 自动化钩子

.users/                     # 用户用（用户语言）
├── context/agents-rules.md   # 详细说明
├── workflows/              # （镜像.agents/）
├── skills/                 # （镜像.agents/）
└── hooks/                  # （镜像.agents/）
```

- **`/init`**: 分析项目后自动生成上下文文件
- **1:1镜像**: `.agents/` ↔ `.users/`变更保持同步
- **AGENTS.md / CLAUDE.md**: 上下文链接的标准入口点

## 🛠️ 图像/文档工具

- **generate_image** — 图像生成 (Nano Banana)
- **analyze_image** — 图像分析 (Gemini)
- **read_document** — HWP, PDF, DOCX, PPTX读取
