# 분석 보고서에 일련번호 추가 및 개수 표시 계획

이 계획은 `work/analysis-of-102-modifications.md` 문서의 각 파일 목록에 일련번호를 추가하고, 각 섹션의 총 파일 개수를 제목에 명시하여 가독성을 높이는 작업을 수행하기 위해 작성되었습니다.

## 1. 목표

- 문서 내의 모든 파일 목록(불릿 리스트)을 번호가 매겨진 리스트로 변경합니다.
- 각 목록의 총 개수를 해당 섹션의 제목에 표시하여 한눈에 파악할 수 있도록 합니다.
- 테이블 형식의 목록은 이미 구조화되어 있으므로 그대로 유지합니다.

## 2. 작업 단계

### 1단계: 파일 읽기
- 수정할 대상 파일인 `work/analysis-of-102-modifications.md`의 전체 내용을 읽어옵니다.

### 2단계: 내용 수정 (번호 매기기 및 개수 업데이트)

1.  **자동 매핑 파일 목록 수정**:
    - `## 🎯 자동 매핑된 32개 파일 목록` 섹션의 불릿 리스트(`- `)를 번호 리스트(`1. `, `2. `, ...)로 변경합니다.
    - 제목을 `## 🎯 자동 매핑된 파일 목록 (32개)`으로 수정하여 총 개수를 명시합니다.

2.  **추가 분석 필요 파일 (백엔드) 목록 수정**:
    - `## 🤖 추가 분석 필요 파일` 아래 `### 백엔드` 섹션의 불릿 리스트를 번호 리스트로 변경합니다.
    - 파일 개수를 세어 제목을 `### 백엔드 (NN개)` 형식으로 업데이트합니다.

3.  **추가 분석 필요 파일 (프론트엔드) 목록 수정**:
    - `## 🤖 추가 분석 필요 파일` 아래 `### 프론트엔드` 섹션의 불릿 리스트를 번호 리스트로 변경합니다.
    - 파일 개수를 세어 제목을 `### 프론트엔드 (NN개)` 형식으로 업데이트합니다.

### 3단계: 최종 파일 작성
- 위의 모든 변경 사항이 적용된 새로운 내용으로 `work/analysis-of-102-modifications.md` 파일을 덮어씁니다.

## 3. 예상 결과
- `work/analysis-of-102-modifications.md` 파일의 목록들이 번호로 매겨져 각 항목을 추적하기 쉬워집니다.
- 각 섹션의 제목에서 파일의 총개수를 바로 확인할 수 있어 문서의 정보 전달력이 향상됩니다.
