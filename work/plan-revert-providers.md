# 프로바이더 파일 원복 계획

## 1. 목표

`litellm`과 `caret`을 제외한 `src/core/api/providers/` 디렉토리 내의 모든 파일을 `upstream/main` 브랜치의 버전으로 원복하여 병합 충돌 및 복잡성을 줄인다.

## 2. 배경

다수의 파일에서 병합 충돌이 발생하여 컴파일이 실패하고 있다. 마스터의 지시에 따라, Caret에서 직접 수정하지 않은 프로바이더 파일들은 `upstream`의 원본 상태로 되돌려 문제를 단순화한다.

## 3. 작업 절차

1.  **대상 파일 식별**: `ls -1 src/core/api/providers/` 명령을 통해 현재 프로바이더 파일 목록을 확인한다.
2.  **원복 대상 확정**: 위 목록에서 `caret.ts`와 `litellm.ts`를 제외한 모든 파일을 원복 대상으로 확정한다.
3.  **계획 제출 및 승인**: 원복 대상 파일 목록과 사용할 `git` 명령어를 마스터께 제출하고 실행 승인을 받는다.
4.  **원복 실행**: 승인 시, `git checkout upstream/main -- <file_path>` 명령을 사용하여 대상 파일들을 순차적으로 원복한다.
5.  **재검증**: 모든 대상 파일 원복 후, `npm run compile`을 실행하여 남아있는 병합 충돌 및 타입 오류를 다시 확인한다.
6.  **후속 조치**: 재검증 결과에 따라 남은 문제들을 해결하기 위한 추가 계획을 수립한다.
